# NovusPal development preview

[Open the NovusPal preview](https://aquaticmarinemammal15.github.io/project-n-preview/).

This is a development preview with sample data and simulated sign-in. It is not an official campus service. Native iOS and Android validation is still pending.

This repository hosts reviewed runtime files in `site/` and minimal GitHub Pages infrastructure. Publishing requires a manual workflow run on `main`; commits and pull requests run integrity checks only.

See the existing [LICENSE](LICENSE) and bundled [third-party notices](site/THIRD_PARTY_NOTICES.txt). Internal development, testing and release records are maintained separately.
