# Preview release, October 20, 2026

First staged preview of the NovusPal Expo app for `https://aquaticmarinemammal15.github.io/project-n-preview/`.

| Item | Value |
| --- | --- |
| Source | `aquaticmarinemammal15/Project-N` branch `project-n`, commit `337589872fc66e1d161dda9921e33f13766e5887`, folder `novuspal/` (private) |
| Build | `NOVUSPAL_BASE_URL=/project-n-preview npx expo export --platform web` (Expo SDK 58, `web.output: "single"`, no source maps) |
| Staged | 41 payload files plus `release-manifest.json`, about 2.35 MB, SPA fallback `404.html` |
| Label | Every screen shows "NovusPal — development preview. Not an official campus service." and "Sample data only: people, numbers and sign-in are made up." |
| Notices | `THIRD_PARTY_NOTICES.txt` lists the license of each bundled npm package (MIT, OFL-1.1 fonts, Apache-2.0 and others) and the OpenStreetMap credit |

Staging used a Node port of `scripts/stage_site.py` on the build PC, which has no Python. It writes the same `.nojekyll`, `404.html` and manifest format and runs the same file, path, credential and link checks. The workflow's `check` and `artifact` jobs run `scripts/validate_site.py site` on GitHub before anything is published.

## Checks run on the build PC

- `npx tsc --noEmit` and `npx expo lint`: clean.
- `novuspal/tests/web/acceptance.js` against the export: 82/82 at `/`, and 82/82 served under `/project-n-preview/` with an index fallback. This covers no preselected place, partial search, contact → place → back with the prior search kept, consistent "Location unavailable", heading focus, 44 px targets, no overflow at 320 and 390 px, guest indicator, campus links and no JavaScript errors.
- Bundle scan: no local paths, `localhost` URLs or credential patterns. The only emails are `@example.edu` and the only phone numbers are in the reserved 555-01xx range. External links go only to `mtu.edu` and `mtu.instructure.com` pages.

## Known limitations

- All people, contact details and sign-in are simulated. Google and SSO buttons are placeholders.
- Direct visits to deep links such as `/project-n-preview/contacts` return HTTP 404 from GitHub Pages while the app still loads from `404.html`.
- Not yet checked on physical iOS or Android devices. Campus-link URLs and the campus safety number still need team confirmation.
